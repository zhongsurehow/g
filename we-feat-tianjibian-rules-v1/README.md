# 天机变 - 易经主题策略卡牌游戏

## 项目简介

天机变是一款融合易经哲学的策略卡牌游戏，通过游戏机制让玩家在娱乐中自然学习易经智慧。游戏包含完整的64卦系统、阴阳平衡机制、五行相生相克等传统文化元素。

## 核心特色

### 🎯 易经教育价值
- **64卦完整体系**：包含所有64卦及其爻辞，每卦都有独特的游戏效果
- **阴阳平衡机制**：玩家需要平衡阴阳两极，体现太极思想
- **五行相生相克**：木火土金水五行系统，展现自然循环规律
- **变卦系统**：模拟易经占卜中的变卦过程
- **天地人三才**：游戏区域设计体现三才思想

### 🎮 游戏机制创新
- **潜移默化学习**：通过游戏机制自然融入易经知识，避免说教式教育
- **多元胜利路径**：传统积分、阴阳大师、五行宗师、变化之道等多种获胜方式
- **智慧格言系统**：激活条件触发易经名言，增强文化体验
- **协同效应**：不同卦象组合产生特殊效果

## 新增系统功能

### 🧠 智慧系统 (Wisdom System)
- **智慧格言库**：收录易经经典名言和智慧语录
- **触发机制**：根据玩家行为和游戏状态智能触发相关格言
- **属性加成**：格言提供气、道行、诚意等属性奖励
- **进度追踪**：记录玩家的智慧学习历程

### 📚 教学系统 (Tutorial System)
- **分类教学**：基础规则、易经知识、策略指导、高级战术
- **互动课程**：包含理论讲解、实例演示、测验问答
- **进度管理**：跟踪学习进度，解锁高级内容
- **奖励机制**：完成课程获得游戏资源奖励

### 🏆 成就系统 (Achievement System)
- **多元成就**：基础、精通、探索、特殊等不同类别
- **实时追踪**：监控玩家游戏行为，自动解锁成就
- **稀有度分级**：普通、稀有、史诗、传说四个等级
- **奖励发放**：成就解锁提供丰厚的游戏资源

### 🃏 增强卡牌系统 (Enhanced Cards)
- **卡牌分级**：基础、进阶、大师、传说四个等级
- **特殊效果**：连击、组合、变化等多样化机制
- **易经融合**：卡牌与阴阳五行、卦象深度结合
- **策略深度**：提供更丰富的战术选择

## 游戏规则详解

### 基础概念

#### 玩家属性
- **气（Qi）**：基础资源，用于各种行动
- **道行（Dao Xing）**：修行进度，主要胜利条件
- **诚意（Cheng Yi）**：特殊资源，用于高级操作
- **阴阳平衡**：阴阳两极的平衡状态
- **五行亲和力**：对五行元素的亲和程度

#### 游戏区域（三才）
- **天部（Tian）**：阳气充盈，冥想获得额外阳气
- **人部（Ren）**：平衡之地，调和阴阳
- **地部（Di）**：阴气深厚，冥想获得额外阴气

### 核心机制

#### 1. 阴阳平衡系统
```python
# 阴阳平衡度计算
balance_ratio = min(yin_points, yang_points) / max(yin_points, yang_points)

# 平衡奖励
if balance_ratio >= 0.8:
    bonus_qi = 2  # 高度平衡奖励
elif balance_ratio >= 0.6:
    bonus_qi = 1  # 基础平衡奖励
```

#### 2. 五行相生相克
- **相生链**：木→火→土→金→水→木
- **相克链**：木克土，土克水，水克火，火克金，金克木
- **效果**：相生增强，相克制衡

#### 3. 变卦机制
- 消耗3点诚意
- 将一个卦象转化为另一个
- 获得目标卦的属性加成
- 记录变卦历史

### 胜利条件

1. **传统路径**：道行达到15点
2. **资源路径**：气达到20点且诚意达到10点
3. **阴阳大师**：阴阳平衡度≥0.9且道行≥10点
4. **五行宗师**：所有五行亲和力≥3点
5. **变化之道**：完成5次变卦且道行≥8点

## 开发指南

### 添加新卦牌

1. 在 `cards_data/` 目录下创建新文件
2. 定义卦牌的爻辞任务：

```python
from card_base import GuaCard, YaoCiTask

# 定义爻辞任务
tasks = [
    YaoCiTask("初九", "潜龙勿用", {"qi": 1}),
    YaoCiTask("九二", "见龙在田", {"dao_xing": 1}),
    # ... 更多爻辞
]

# 创建卦牌
NEW_GUA = GuaCard(
    name="新卦名称",
    associated_guas=["相关卦象"],
    tasks=tasks
)
```

3. 在 `generate_64_guas.py` 中添加到相应宫组

## 易经知识背景

### 八卦基础
- **乾（☰）**：天，创造力，阳刚
- **坤（☷）**：地，包容性，阴柔
- **震（☳）**：雷，动力，长男
- **巽（☴）**：风，渗透，长女
- **坎（☵）**：水，险阻，中男
- **离（☲）**：火，光明，中女
- **艮（☶）**：山，静止，少男
- **兑（☱）**：泽，喜悦，少女

### 64卦体系
64卦由八卦两两组合而成，每卦包含：
- **卦名**：如"乾为天"、"坤为地"
- **卦象**：上下两个三爻卦组成
- **爻辞**：六个爻位的具体含义
- **卦辞**：整卦的总体意义

### 哲学思想
- **阴阳互补**：对立统一的辩证思维
- **五行循环**：自然界的基本规律
- **变化之道**：万物皆变的动态观
- **天人合一**：人与自然的和谐统一
